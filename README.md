# Dự án: Ứng dụng hình học của Tích phân

Dự án tổng hợp kiến thức, lý thuyết và bài tập về ứng dụng hình học của tích phân (tính diện tích hình phẳng, thể tích khối tròn xoay), được biên soạn bằng ngôn ngữ Typst.

## Danh mục tài liệu

1. **01-dien-tich-hinh-phang.typ**: Tính diện tích hình phẳng giới hạn bởi các đường cong.
2. **02-the-tich-khoi-tron-xoay.typ**: Tính thể tích vật thể và thể tích khối tròn xoay.
3. **03-do-dai-cung-va-dien-tich-mat-xoay.typ**: Tính độ dài cung tròn và diện tích mặt tròn xoay.
4. **04-bai-tap-tong-hop.typ**: Các bài toán thực tế và nâng cao.

## Hướng dẫn sử dụng
Để biên dịch các file `.typ` sang PDF, bạn cần cài đặt [Typst](https://typst.app) và chạy lệnh:
`typst compile ten-file.typ`
